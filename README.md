## Sobre mim

Gosto de transformar ideias em projetos que realmente funcionam — da lógica no código ao protótipo montado na bancada. Minha formação combina desenvolvimento de software, aplicações web e eletrônica com microcontroladores.

- 🐍 Desenvolvo aplicações e automações com **Python**.
- ⚙️ Estudo **C++**, lógica de programação e programação orientada a objetos.
- 🔌 Crio protótipos com **ESP32**, sensores, displays e comunicação entre hardware e software.
- 🌐 Desenvolvo interfaces e sistemas web com **HTML, CSS e JavaScript**.
- 📚 Estou sempre melhorando meus projetos, documentação e boas práticas.
- 🎯 Busco oportunidades para aprender, colaborar e gerar resultado com tecnologia.
